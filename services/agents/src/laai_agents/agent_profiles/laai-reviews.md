# Focal Reviews

![tag:shopping](https://img.shields.io/badge/shopping-3D8BD3) ![tag:reviews](https://img.shields.io/badge/reviews-3D8BD3)

Summarizes independent expert reviews of a product. It normalizes each site's score to a 5-point scale, averages them, and lists the main pros and cons with a link to every review. Each site counts once.

## Try it
- "Reviews of the Sony WH-1000XM5"
- "Is the Samsung Galaxy Buds3 Pro any good?"

Part of the Focal team; the coordinator is `focal-shopping-assistant`.
