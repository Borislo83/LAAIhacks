# Focal Memory

![tag:memory](https://img.shields.io/badge/memory-3D8BD3) ![tag:personalization](https://img.shields.io/badge/personalization-3D8BD3)

The Focal team's long-term memory. It recalls a shopper's preferences (shopping priority, notes) from their Focal Studio profile (read-only, Supabase), and keeps their past research and decisions so later recommendations fit them.

Every reply includes the request it made and the response it got, so the coordinator can show the call in the chat. Shoppers are keyed by a hash of their address, and nothing personal is shared with other agents.

Part of the Focal team; the coordinator is `FOCAL`.
