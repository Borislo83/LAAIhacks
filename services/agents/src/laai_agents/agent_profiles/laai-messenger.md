# Focal Messenger

![tag:messaging](https://img.shields.io/badge/messaging-3D8BD3) ![tag:imessage](https://img.shields.io/badge/imessage-3D8BD3)

Drafts an iMessage to an allowlisted friend ("text Alex I'm running late") and sends it **only after approval**. Recipients come only from a fixed allowlist, never from the request. Each draft expires after 5 minutes and can be used once. Sends are rate-limited, and message text is never logged.

Part of the Focal team; the coordinator is `focal-shopping-assistant`.
