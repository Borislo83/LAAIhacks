# Focal News

![tag:news](https://img.shields.io/badge/news-3D8BD3) ![tag:summarization](https://img.shields.io/badge/summarization-3D8BD3)

Answers "what's the latest on X" with a short, sourced summary of recent coverage. It reads several article pages and returns a headline, a summary of 2 to 4 sentences, a lead image and links to every source.

## Try it
- "What's the latest on SpaceX Starship?"
- "News about the Fed rate decision"
