# Focal YouTube

![tag:youtube](https://img.shields.io/badge/youtube-3D8BD3) ![tag:music](https://img.shields.io/badge/music-3D8BD3)

Turns a request like "find the song Blinding Lights" or "video on how to tie a tie" into one YouTube video link, plus up to three alternatives. For songs it looks for the official audio. Returns only single-video `youtube.com/watch` links; shorts, playlists and channels are dropped.

## Try it
- "Find the song Bohemian Rhapsody"
- "YouTube link for how to change a bike tire"
